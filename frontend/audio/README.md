# Music

Drop one background track here (e.g. `song.mp3`) and set its filename in
`frontend/pages.js` via `window.BIRTHDAY_AUDIO`. Set it to `''` to disable
audio. The track loops and plays after Emma taps "Tap to begin" (browsers
block autoplay until that first gesture).

Keep it reasonably small (a few MB). MP3 is the safest cross-browser format.
